# Conversor NFC

Site estático, sem dependências ou etapa de compilação. Os arquivos já estão na raiz do repositório.

Para publicar gratuitamente no GitHub Pages, abra **Settings → Pages** e selecione **Deploy from a branch**, a branch `main` e a pasta `/(root)`. Salve; o endereço ficará disponível nessa tela após a publicação.

O conversor funciona inteiramente no navegador e não transmite os códigos digitados.
