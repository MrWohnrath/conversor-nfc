# Conversor NFC

Site estático, sem dependências ou etapa de compilação. Para publicar gratuitamente no GitHub Pages:

1. Crie um repositório público chamado `conversor-nfc` e envie os arquivos desta pasta para a raiz.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)` e salve.
3. O GitHub Pages mostrará o endereço público do site nessa mesma tela.

O conversor funciona inteiramente no navegador e não transmite os códigos digitados.
